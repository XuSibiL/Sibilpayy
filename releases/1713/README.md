# 1713 — اتصالِ خودکارِ ربات‌ها

هیچ ثبتِ دستی لازم نیست. فاکتور آدرسِ خودش را با خودش می‌آورد و خبرِ
`invoice.paid` به همان آدرس برمی‌گردد.

- `callback_url` فیلدِ شناخته‌شدهٔ API است؛ `webhook_url` هم همان حساب می‌شود.
- اگر هیچ آدرسی نفرستند، هدرِ `Origin` (یا `Referer`) با `X-Webhook-Path` استفاده می‌شود.
- اگر آن هم نبود، آخرین دامنه‌هایی که از همین فروشگاه فاکتور ساخته‌اند.
- سقف سه مقصد؛ هر مقصد با کلیدِ امضای خودش.

فایل‌ها: `fix4.py` (بک‌اند)، `fix5.py` (ربات)، `conn_repo.py` و `conn.py` (پنلِ اتصالات).
