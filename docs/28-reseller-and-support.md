# ۲۸ — کد فروشندگی و پشتیبانی

## کد فروشندگی

هر فروشگاه یک کد عمومی دارد، شش تا دوازده کاراکتر از حروف بزرگ و رقم، مثل `SB4K9QX`. با این کد می‌شود فروشگاه تازه ساخت و درآمد معرفی گرفت.

- فروشگاه تازه با فیلد `referred_by_code` ساخته می‌شود.
- وقتی فروشگاه معرفی‌شده یک پرداخت تأییدشده بگیرد، سهم معرف از کارمزد پلتفرم به کیف او اضافه می‌شود.
- این سهم از کارمزد پلتفرم پرداخت می‌شود، نه از پول خریدار و نه از کیف فروشگاه تازه.
- نرخ هر معرف جدا تنظیم می‌شود (`commission_bps`، بر مبنای ۱۰٬۰۰۰) و بیشتر از ۱۰٬۰۰۰ پذیرفته نمی‌شود؛ یعنی بیش از ۱۰۰ درصد کارمزد، معنی ندارد.
- ثبت درآمد با نوع `commission` در `wallet_transactions` می‌آید، پس در گردش کیف دیده می‌شود.
- اگر سهم صفر شود، چیزی ثبت نمی‌شود و کیف دست نمی‌خورد.

## پشتیبانی و تیکت

تیکت‌ها با لینک امضاشده کار می‌کنند و کلید API نمی‌خواهند. لینک فروشگاه و لینک پشتیبانی جدا ساخته می‌شوند و توکن هر کدام با شناسه خودش امضا می‌شود.

| مسیر | کار |
|---|---|
| `GET /support/t/{store_id}/{token}` | فهرست تیکت‌های همان فروشگاه |
| `POST /support/t/{store_id}/{token}/new` | تیکت تازه |
| `GET /support/t/{store_id}/{token}/t/{ticket_id}` | یک تیکت با پاسخ‌ها |
| `POST /support/t/{store_id}/{token}/t/{ticket_id}/reply` | پاسخ فروشنده |
| `GET /support/admin/{token}` | فهرست تیکت‌ها برای پشتیبانی، با فیلتر وضعیت |
| `GET /support/admin/{token}/t/{ticket_id}` | یک تیکت در پنل پشتیبانی |
| `POST /support/admin/{token}/t/{ticket_id}/reply` | پاسخ پشتیبانی |

وضعیت‌های تیکت:

| وضعیت | معنی |
|---|---|
| `open` | منتظر جواب پشتیبانی |
| `answered` | پشتیبانی جواب داده و منتظر فروشنده است |
| `closed` | بسته شده |

قاعده وضعیت خودکار: پاسخ پشتیبانی تیکت را `answered` می‌کند، و پاسخ فروشنده روی تیکت `answered` یا `closed` آن را دوباره `open` می‌کند. همان لحظه هم در تلگرام به دو طرف اطلاع داده می‌شود.

اگر توکن لینک عوض شده باشد صفحه باز نمی‌شود. توکن را ذخیره نکن و لینک را از ربات دوباره بگیر.

## چک‌لیست

- [ ] کد فروشندگی را با حروف بزرگ و بدون فاصله می‌فرستم.
- [ ] برای پشتیبانی، لینک فروشگاه را با لینک پشتیبانی قاطی نمی‌کنم.
- [ ] لینک تیکت را در لاگ عمومی نمی‌گذارم؛ خودش توکن دارد.
